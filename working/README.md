# working/ — personal scratch space

Everything in this folder is **git-ignored** (only this `README.md` is tracked). Use it for personal
notes, content review digests, throwaway scripts and exported reports that should sit next to the code
but never be pushed.

Nothing here is reviewed. Anything that matters long-term belongs in `docs/`, `specs/` or `memory-bank/`.

## For AI agents (Claude Code)

- Treat `working/` as private scratch. **Do not** stage, commit or push anything from here.
- Reading, creating and editing files here is fine when drafting something personal.
- The git-ignore rule lives in the root `.gitignore` (`/working/*` with `!/working/README.md`).
