# Project Brief — InterviewPrep

## What it is

A single-user, locally-run interview-preparation platform for a Senior Full-stack engineer
(Angular + .NET + AI Engineering). It turns a curated knowledge taxonomy into reviewable content
(notes, MCQs, open questions, code katas), schedules review with spaced repetition (SM-2 in MVP),
and uses the Anthropic API only where judgment is required (grading open answers and katas,
personalised "why you were wrong" reviews).

## Why it exists

- Interview prep at senior level needs **retrieval practice**, not reading. Notes alone don't stick.
- Existing tools (Anki, generic quiz apps) don't carry senior-level, stack-specific content with
  rubric-graded open answers.
- Building it is itself a showcase of AI-augmented development: spec-driven workflow, subagents,
  content generated by an agent and reviewed by a human.

## Core requirements

### Functional (MVP)

- Knowledge graph domain → topic → concept, seeded from `content/**/*.json` (validated by schema,
  imported by a CLI command, upserted by slug/id).
- Notes per concept (Markdown, code samples), language switch `en`/`uk`.
- Daily review session: due questions (SM-2) + new ones, MCQ with instant feedback, session summary.
- Open questions and katas graded by an LLM against a rubric with structured output; graceful
  fallback when no API key.
- Per-domain readiness number.

### Non-functional

- One command to run: `docker compose up` (postgres, api, web) with health checks.
- English canonical content; Ukrainian translations as a separate pass.
- Progress tables are user-scoped from day one (single seeded user) so multi-user stays possible.
- Tests only where they pay: scheduling, import, grading parsing, one integration test per module.

## Explicit non-goals (MVP)

Authentication, multi-user, billing, voice mock interviews, in-browser code execution, React
content, mobile app, dashboards beyond the readiness number.

## Source of truth

`.specify/memory/constitution.md` (principles) and `specs/000-taxonomy.md` (content scope).
